max: [number]
min: [number]
peak number: [count or approximate count]
valley number: [count or approximate count]
peak description: [briefly describe whether peaks are similar or if some are notably stronger — must match the stated peak number]

notable transitions: [short note on sudden motion bursts, shifts, or recoveries]

summary: [≤50 words concise synthesis of all the above observations into a coherent motion description, if there are some feature on the plot that is not listed above, also mention it here]

Rules:
Use numeric values (e.g., max: 2.35).
Be concise, analytical, and objective — no filler words.

Output only the listed fields, nothing else.

The number of peaks and valleys mentioned in descriptions must align with peak number and valley number.
If peak number = 2, the peak description must reference two peaks.
If trend indicates increase or decrease, the summary should reflect that same directional change.

“Value change summary” should describe how the motion magnitude evolves over time.

The summary must integrate all observations (peaks, valleys, stability, periodicity, and overall motion evolution) into a concise, coherent statement.
